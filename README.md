# alu-scripting

Scripting projects using Python and the Reddit API.

## api_advanced
- `0-subs.py`: function that returns the number of subscribers of a
  given subreddit (0 if the subreddit is invalid).
  - `1-top_ten.py`: function that prints the titles of the first 10 hot
  posts of a given subreddit (None if the subreddit is invalid).
